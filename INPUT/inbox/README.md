# INBOX — Bandeja de entrada

Carpeta temporal. Dejás archivos acá → yo los proceso y los muevo al proyecto correspondiente.

## Estructura

```
inbox/
├── MENTE PAUSADA/   ← audios, imágenes, PDFs, docs de RMC
├── POLT MOBILIER/   ← fotos de proyectos, docs de clientes, materiales
└── CEREBRO/         ← reportes, capturas, ideas, oportunidades
```

## Cómo funciona

1. Copiás el archivo en la carpeta del proyecto que corresponde
2. Me avisás "hay archivos en inbox" o simplemente lo mencionás
3. Yo reviso, determino a dónde va dentro del proyecto, lo muevo y confirmo

## Regla: inbox siempre debe quedar vacía después de cada proceso
