### 4. PROMPTS MAESTROS DE CONTENIDO

**Archivo:** `prompts/PROMPT_MAESTRO_CONTENIDO.md`

**Cómo usarlos:**
1. Abrir AI Studio (aistudio.google.com) — Gemini Flash, gratis sin límite
2. Pegar el prompt maestro (hay uno para Mente Pausada y otro para Polt)
3. Reemplazar `{{GANCHO}}` con la idea cruda
4. El JSON que devuelve tiene: guión, caption, hashtags, prompt imagen, prompt video Kling
5. Tomar `prompt_imagen` → ChatGPT o Freepik para la imagen
6. Tomar `prompt_video_kling` → Kling 2.5 en Freepik (gratis) para el video

**Workflow completo:**
```
Idea cruda → AI Studio → JSON → imagen (Freepik/ChatGPT) → video (Kling 2.5) → publicar
```
